# LayoutKart Cloth Store — Shopify Theme

Premium Shopify theme for clothing/fashion stores, built for Indian sellers.

## Structure
- `assets/` — CSS, JS, images
- `config/` — theme settings
- `layout/` — theme.liquid (main layout)
- `locales/` — translations
- `sections/` — homepage sections (hero, collections, products, etc.)
- `snippets/` — reusable components (product cards, etc.)
- `templates/` — page templates
